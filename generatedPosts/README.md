# Generated posts

Each worked TikTok post lives in its own folder:

```
generatedPosts/{YYYY-MM-DD}/post_NNN/
```

`NNN` is a three-digit counter that starts at `001` and increments for every new post on that calendar day. Do not reuse a number. Do not use a bare `post/` folder.

Examples:

```
generatedPosts/2026-09-09/post_001/
generatedPosts/2026-09-09/post_002/
generatedPosts/2026-09-10/post_001/
```
